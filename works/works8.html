クイズアプリ / Udemy課題

  • Webサイト
  • コード
概要
Udemy講座内で制作したクイズアプリです。
使用技術
HTML / CSS / JavaScript / PHP
製作日数
14日間
取り組み内容
  • Udemy課題をベースに、ページの余白や下線の色を調整し、より見やすくなるようアレンジしました。
  • PHPを用いたサーバー側の処理に取り組み、問題の出題から回答判定までの一連の流れを実装しました。
  • AWSに仮想サーバーを構築し、作成したプログラム（PHPファイル）をサーバーにアップロード・管理することで、アプリが動作する環境を整えました。
  • お名前.comで独自ドメインを取得し、公開環境を整えました。
  • SSL/TLS証明書を導入することで、通信内容が安全にやり取りされるように設定し、セキュリティ面を強化しました。
  • PHPについては理解が難しい部分もありましたが、処理の流れを追いながら実装することで、Webアプリの動作への理解を深めました。
