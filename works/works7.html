天気予報アプリ / Udemy課題

  • アプリ
  • コード
概要
Udemy講座内で制作した天気予報アプリです。
使用技術
HTML / CSS / JavaScript
製作日数
2日間
取り組み内容
  • Udemy課題として作成した天気予報アプリについて、より分かりやすく使いやすい形に改善しました。
  • 元の課題は、自分のパソコン上でしか動作せず、他の人が利用できない状態だったため、Webアプリとしてブラウザ上で動作し、誰でも利用できる形に作り替えました。
  • 元の課題は、「郵便番号を入力して天気情報を取得する」仕様でしたが、実際には調べたい地域の郵便番号を把握しているケースは少ないため、より実用的な「都市名で検索できる仕様」に変更しました。
  • HTMLで都市名を入力できるフォームを作成し、リアルタイムで取得した天気情報の結果をブラウザ上に表示するようにしました。
  • CSSを用いてレイアウトを調整し、シンプルながら見やすい画面構成を意識しました。
  • JavaScriptで外部の天気情報サービス（OpenWeather API）と通信し、取得した天気情報をブラウザ上に表示するようにしました。
  • 作り替えるにあたり、大幅なコードの変更が必要となるJavaScriptについては、Udemy課題の段階から理解が難しい部分もありましたが、Copilotの提案を参考にしつつ、動作確認や調整を繰り返しながら理解を深めて実装しました。
